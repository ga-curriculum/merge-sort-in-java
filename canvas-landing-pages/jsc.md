## About

Merge sort algorithm is called merge sort because it works on the premise that merging two sorted lists together is the easiest way to create a single sorted list. Merge sort is a divide-and-conquer algorithm that is especially useful for handling large datasets due to its stable sorting capabilities and predictable time complexity. In this module, lets learn what a merge sort algorithm is and how to implement it using Java code.
